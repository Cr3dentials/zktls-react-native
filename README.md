# zktls-react-native

React Native bridge for the Cr3dentials zkTLS native SDK

## Installation


```sh
npm install zktls-react-native
```


## Usage


```js
import { multiply } from 'zktls-react-native';

// ...

const result = multiply(3, 7);
```
